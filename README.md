
# 🛡️ AI SOC Monitoring System

An AI-powered Security Operations Center monitoring project built using Machine Learning, React, FastAPI, and SQLite.

## 🚀 Features

- Analyst Sign Up and Sign In
- Password Hashing and JWT Authentication
- Security Alerts Dashboard
- Machine Learning-Based Threat Detection
- Alert Severity and Status Tracking
- Alert Investigation
- Charts and Security Reports
- CSV Export

## 🛠️ Tech Stack

**Frontend:** React, JavaScript, CSS, Vite

**Backend:** Python, FastAPI

**Machine Learning:** Scikit-learn, Isolation Forest

**Database:** SQLite

**Version Control:** Git and GitHub

## 🎯 Project Objective

To demonstrate how machine learning can help SOC analysts identify suspicious login activity, monitor security alerts, and investigate potential threats.

## 📌 Project Status

Under active development.

This is an educational demonstration project, not a production-ready security monitoring platform.

## 🔐 Security Note

Never commit secret keys, real credentials, or user databases to a public repository.
